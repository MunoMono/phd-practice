# Turin Authority Register

Authority support is an apparatus layer, not documentary evidence.

Permitted roles: entity resolution, transparent query expansion, filters, optional structural context, and corroborative checking. A saved run records authority source, authority type/ID, role, fields used, query expansion produced in retrieval transparency, snapshot/version, and whether authority context was supplied to Granite.

The current context builder labels supplied authority material as `ARCHIVE / DATABASE AUTHORITY CONTEXT`; it is never merged into a `SOURCE DOCUMENT EVIDENCE` block. Document-only runs record that authority context was not supplied.

Researcher review should note any authority influence in the separate assessment. Authority data cannot independently support a generated historical claim or citation.
