# Turin Experiment Evaluation Rubric

Assessment is researcher-authored and stored separately from immutable experiment evidence.

Each scored field uses 0–3:

- `0`: absent, misleading, or materially unsuitable.
- `1`: limited; substantial correction or qualification required.
- `2`: usable with explicit qualifications.
- `3`: strong and appropriately bounded for the supplied evidence.

Assess: retrieval relevance, provenance accuracy, interpretative restraint, preservation of contestation, and missingness handling.

Record qualitative notes, optional failure classifications, and an authority-influence observation. Failure classifications describe the run or method boundary; they are not an automated model-quality verdict.

Check that citations resolve only to supplied source-document evidence; authority assertions, where present, resolve only to separately supplied authority context. Check that missingness is scoped to the current query/evidence/corpus and never recast as historical absence.
